# Математическая модель и ограничения

## Переменные и размерности

Состояние: пройденная продольная координата s [м], продольная скорость v [м/с]. Вспомогательные оценки: ускорение a [м/с²] и ограниченная поправка d [м/с²]. Вход u ∈ {−15,…,15}; измерения z_f=k w_f, z_r=k w_r. k=0,277779984843 для предоставленной записи; выходной SI-масштаб не зависит от единиц входа.

Предполагается движение вперёд. Небольшие отрицательные скорости около нуля отсекаются; полноценное движение задним ходом не реализовано. Команда с отрицательным знаком означает торможение.

## Нелинейная продольная динамика

Пусть p=max(u,0)/15, b=max(−u,0)/15. Тогда:

```
a_model = (c0*p + c1*p²)/(1 + v/12)
          − c2*b − c3*b²
          − c4*tanh(v/0.3) − c5*v/15 − c6*v²/225
```

Коэффициенты из обучения: c0=1,8056718113; c1≈0; c2=1,8676578225; c3≈0; c4=0,0183427628; c5=0,0609468263; c6≈0. При фиксированных нормировках все c имеют размерность ускорения. Скоростная зависимость тяги и tanh обеспечивают нелинейность, даже когда некоторые коэффициенты оптимизации близки к нулю.

Эквивалентная силовая запись: m_eff·dv/dt = F_traction − F_brake − F_resistance + F_disturbance. Для заданных массы, радиуса r, передаточного отношения i и КПД η момент двигателя связан с силой как T_motor=F_traction·r/(iη), с поправкой на число приводов при необходимости. Сам датасет не позволяет независимо определить массу, радиус, КПД и момент; поэтому численно оцениваются идентифицируемые отношения сил к эффективной массе. Выдуманные паспортные параметры в модель не подставлялись. Уклон, масса и сцепление отдельно не восстановлены.

Ускорение приближается к a_model+d через апериодическое звено с τ=0,25 с. После принятого измерения дополнительно корректируется по производной скорости той же тележки. d адаптируется только при согласованных принятых колёсных данных и ограничен ±0,6 м/с². Ускорение ограничено ±3 м/с². Эти значения — конфигурируемые предположения для прототипа.

Дискретный прогноз: v_next=max(0,v+a·dt); s_next=s+(v+v_next)·dt/2. Для больших временных промежутков число шагов ограничено; при длительной потере достоверных колёс алгоритм переходит к движению с примерно постоянной скоростью и увеличивает неопределённость.

## Коррекция и достоверность

Вектор [s,v] корректируется линейным измерением H=[0,1] внутри нелинейного предсказателя. Это модельный наблюдатель с коррекцией Калмана, не UKF. Для ковариации используется локальная модель постоянной скорости F=[[1,dt],[0,1]] и шум ускорения. Нелинейное ускорение и адаптация не включены полностью в состояние ковариации: опубликованные ковариации ориентировочные, статистическая согласованность NEES/NIS не подтверждалась.

Колёсные измерения принимаются один раз. Межпоточные опоздания до 0,25 с компенсируются текущим ускорением с увеличением дисперсии; более старые сообщения игнорируются. Внутрипоточные дубликаты и обратный ход Header отбрасываются.

Подозрения формируются по рассогласованию тележек, инновации относительно модели и слишком резкому скачку одной тележки. При противоречии предпочтение получает измерение ближе к прогнозу; подозрительные измерения отклоняются. Повторный захват длительно согласованных данных допускается через 3 с отсутствия принятых измерений. Совместное длительное согласованное скольжение обеих тележек может быть ошибочно принято: полностью наблюдаемого независимого измерителя скорости нет.

Нулевой сброс скорости разрешён при двух свежих почти нулевых показаниях и уже малой оценке скорости. Блокировка одного колеса при большой скорости нулевой сброс не вызывает. Абсолютную точность при длительной блокировке обоих колёс гарантировать нельзя.

## Геометрия и GNSS

Во входе Estimator нет GNSS-аргументов. Отдельный PositionTracker принимает GNSS только в ограниченном начальном окне. После его закрытия новые GNSS не влияют на скорость, s или геометрическую позицию.

Начальный курс может задаваться конфигурацией, GNSS-скоростью или двумя начальными GNSS fix. На обучающей части обнаружено, что направление master→rover совпадает с направлением движения, базовая длина около 12,4 м. Это свойство конкретных записей и монтажа, а не универсальное соглашение ROS; dual_gnss_heading можно отключить.

При известной упорядоченной карте положение задаётся r(s), направление — касательной к полилинии. Начальная координата вдоль маршрута выбирается по GNSS/курсу либо задаётся вручную. Ветвления и выбор стрелок не решены; неоднозначная начальная проекция выдаёт ошибку.

Без карты: r(s)=r0+(s−s0)[cos(yaw0),sin(yaw0),0]. Этот режим оценивает продольный путь, но не кривую траекторию. Несколько различных траекторий с одинаковой скоростью и одинаковым начальным курсом создают одинаковые три разрешённых входа. Поэтому поворот после GNSS-окна невозможно однозначно восстановить. Высота также удерживается без геометрии маршрута.
